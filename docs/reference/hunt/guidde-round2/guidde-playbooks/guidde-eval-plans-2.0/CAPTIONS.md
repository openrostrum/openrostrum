## 05 — Additional Configuration  [docScreenshot]
`05.png`
_desc:_ Additionally, there are 4 settings you can configure.

'Set Plan as Open'. If enabled, you can set a due date. If the plan remains closed, you can open the plan at a later date. Until then, plans are "view-only" to evaluators. 

'Enable Anonymized Review'. The first & last names of session speakers are removed from submission details.

'Enable Weekly Reminders'. Have an automated email sent to evaluators every Monday when there are sessions to review in their plan.

'Include Uploaded Files'. Toggle this option on if you want evaluators to view and access any files uploaded to sessions. To learn more about this feature, watch our Session Files Training Video.

## 14 — Limits  [docScreenshot]
`14.png`
_desc:_ Lastly, you can set an evaluation limit that tells your evaluators how many times the evaluation team should review each submission. The number of evaluations per session is tied to the number of evaluators assigned to the plan. For example, If four evaluators are assigned to the plan, each submission can be reviewed a maximum of four times. 

Once you are complete, click the Add Plan button to create your evaluation plan.
